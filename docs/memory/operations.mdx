## REST API

The dashboard contract is unchanged:

| Endpoint | Behavior |
|---|---|
| `POST /memories` | Store content verbatim (`infer` is accepted but ignored in the Markdown backend) |
| `GET /memories` | List by `user_id` / `agent_id` / `run_id`, or admin-list all |
| `POST /search` | Hybrid full-text + vector search; `explain=true` returns score details |
| `PUT /memories/{id}` | Update text, metadata, or expiration |
| `GET /memories/{id}/history` | Audit rows from `memory_history` |
| `DELETE /memories/{id}` | Delete the Markdown entry and index row |
| `POST /reset` | Archive every user workspace under `.trash/<timestamp>/`, then clear the index |

## Agent tools

| Tool | Effect |
|---|---|
| `search_memories` | Read; hybrid search scoped to the signed-in user |
| `get_memory` | Read one entry |
| `save_memory` | Write a curated entry to `MEMORY.md` (identity to `USER.md`) |
| `update_memory` / `delete_memory` | Write; optionally require human approval via `AGENT_MEMORY_REQUIRE_APPROVAL` |

## Maintenance

```bash
# Re-parse every user's files into the index
python -m app.memory.cli reconcile --all

# One user only
python -m app.memory.cli reconcile --user <uuid>

# Delete daily episode files older than the retention window
python -m app.memory.cli prune --retention-days 180
```

Startup and periodic reconciliation are controlled by `AGENT_MEMORY_RECONCILE_ON_START` and
`AGENT_MEMORY_RECONCILE_INTERVAL_SECONDS`. A crash between the file write and the index commit
leaves the user marked dirty; the next reconcile repairs it.

## Configuration

| Variable | Default | Purpose |
|---|---|---|
| `AGENT_MEMORY_ROOT` | `/app/memory` | Authoritative workspace root |
| `AGENT_MEMORY_RECALL` | `true` | Enable per-turn recall |
| `AGENT_MEMORY_RECALL_TOKENS` | `1500` | Query-recall token budget |
| `AGENT_MEMORY_RECALL_MAX` | `15` | Maximum query hits |
| `AGENT_MEMORY_RECALL_THRESHOLD` | `0.4` | Minimum relevance |
| `AGENT_MEMORY_CAPTURE` | `true` | Append episodes after completed turns |
| `AGENT_MEMORY_EPISODIC_RETENTION_DAYS` | `180` | Daily-file retention for `prune` |
| `AGENT_MEMORY_REQUIRE_APPROVAL` | `false` | Confirm memory updates/deletes |
